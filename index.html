Source of truth

Edit the JSON.
Never hand-edit anywhere else.

schema/cybergrid.json is readable by every language in the framework, not just Rust — cyberdock's C++/QML loads it directly at runtime with QJsonDocument; Rust projects get it include_str!-embedded at compile time for zero runtime cost and zero drift risk.

Everything else about the feel — fonts, a type scale, spacing, radii, motion, z-index — lives in cybertokens.css, loaded the same way on every surface.

  "schema_version": 1,
  "palette": {

    "hot_pink": "fd3e6a"

    …
  }
}
